# Santander Bootcamp 2025 - Automação com N8N (DIO)

Participei do Santander Bootcamp 2025 promovido pela DIO e Santander Open Academy, com foco em automação de processos e integração de serviços utilizando o N8N. O bootcamp foi uma excelente oportunidade para aprender, de forma gratuita, sobre automação, produtividade e integração de sistemas, temas essenciais para o mercado de tecnologia atual.

## Módulos e Cursos Realizados

- Introdução a N8N & Workflows
- Primeiros Passos com N8N: Conceitos e Instalação
- Navegação e Interface do N8N
- Criação de Workflows Simples no N8N
- Utilizando Nós Padrão do N8N
- Integração com Serviços Populares no N8N
- Automatizando Processos com N8N
- Manipulação de Dados e Variáveis no N8N
- Uso de Webhooks e APIs no N8N
- Associando Conceitos Iniciais do N8N (Desafio de Código)
- Live de Lançamento: Santander Bootcamp 2025 - 2º Semestre

## O que Aprendi

Durante o bootcamp, aprendi a instalar, configurar e utilizar o N8N para criar automações, integrar diferentes serviços e manipular dados de forma eficiente. Os conteúdos abordaram desde conceitos básicos até práticas intermediárias, proporcionando uma visão completa sobre automação de fluxos de trabalho.
